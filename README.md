## Running a project locally

```bash
cd project-name
npm install
npm run dev
```

Static sites without a build step can just be opened in the browser.

## How to add a project

1. Create a folder named after the project (kebab-case).
2. Add a README with a screenshot, the stack, and the live URL if it is deployed.
3. Add a row to the table above.
